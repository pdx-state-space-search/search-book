# Book authoring

For chapter drafting, substantive revision, or editorial
review, use the repository-local skill:

[search-book-authoring](.agents/skills/search-book-authoring/SKILL.md)

Its editorial guide and examples define the shared teaching
style. Read BRIEF.md, current feedback, and the requested
chapter scope before applying it. New explicit user decisions
supersede earlier notes. Review-only requests do not authorize
chapter edits. This routing supplements applicable parent
instructions; it does not grant commit or push permission.
